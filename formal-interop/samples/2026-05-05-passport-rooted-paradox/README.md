# Passport-Rooted Paradox Formal Interop Sample

This sample converts the same argument-map source into three formats so the output quality can be compared before the pipeline commits to any one language.

## Files

- `argument.argdown` — reader-facing argument map with support and attack edges.
- `comparison.md` / `comparison.zh-TW.md` — English and Traditional Chinese comparison notes.

## Early Read

Argdown preserves the article's argumentative shape best. It is the selected public interoperability format for the next phase.

DeLP is useful for the parts of civic proof that are naturally defeasible, but it is parked for now.

Lean is useful only after the philosophical and empirical premises have already been fixed, but it is parked for now.

## Provisional Recommendation

Use `argmap.yaml` as the canonical internal format, add Argdown export first, and keep DeLP / Lean as optional research-lab views for selected articles.
