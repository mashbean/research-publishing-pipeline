# Example Job Folder

每篇文章都應該有自己的 job folder。

建議內容：

- `intake.yaml`
- `deep-research-packet.yaml`
- `state.json`
- `raw/`：使用者原始材料、PDF、逐字稿
- `sources/`：來源清單與下載資料
- `notes/`：source notes、outline、risk notes
- `drafts/`：research draft、rewrite draft
- `verification/`：evidence map、fact-check report
- `final/`：最終正文
- `publish/`：commit、deploy、live verify 紀錄
