# Readability Agent（拆鷹架）

## 為什麼有這一階段

2026-07-30 的〈中國基層參與的三十年〉發稿後，使用者的回饋是「過於咬文嚼字，各種難以閱讀的循環與論證」。

事後檢查發現這不是單篇失手，是**流程的結構性缺口**：

- accent pass（Step 7.5）原本身兼兩職——讓文章像人寫的、也讓它好讀
- 學術模式（預設）整個關掉 accent pass
- 於是 **沒有任何一關負責可讀性**
- 而 writer → critic → rewrite → editor 每一關的目標函數都是「更嚴謹」：critic 要求補限定語、rewrite 照 critic 補、editor 檢查有沒有補
- 結果是文章不斷累積論證鷹架，沒有人負責拆

**這一階段專責拆鷹架。它不改變論證、不改變語氣人格、不加 accent。**
它與 accent pass 的差別：accent 是「讓它像 mashbean 寫的」，readability 是「讓它讀得下去」。學術模式不要前者，但一樣需要後者。

## 觸發條件

- 學術／無 accent 模式（預設）：**必跑**，位置在 editor 之後、publish 之前
- opt-in accent 模式：**跳過**，accent pass 已涵蓋（accent 的口語化本身就會拆掉鷹架）

## 必讀

1. `<job-dir>/final/article-final.md`（基底）
2. `<job-dir>/intake.yaml`（must_do／must_avoid 是硬約束）
3. `<job-dir>/verification/fact-check-report.md`（確認哪些限定語是 critic 要求補的，那些**不可刪**）

## 四類病灶（照順序清）

### 病灶 1：段落第一句在描述「這段的功能」而不是講事情

**這是最重要的一類，也是「AI 味」最集中的地方。**

| 症狀 | 改法 |
|---|---|
| 「**第一條證據來自「起」的時期內部。**Fewsmith 在 2013 年的專書裡…」 | 刪掉宣告句，直接「Fewsmith 在 2013 年的專書裡…」 |
| 「**先確立正面的事實。**趙琦 2020 年發表於…」 | 刪掉宣告句 |
| 「**第一個限定是幅度。**6,183 萬元分攤到十三年…」 | 刪掉標號，直接給數字 |
| 「**接著必須把限定條件說完**，否則這組數字會被誤讀。」 | 整句刪除，讓下一段直接講 |
| 「**曲線的形狀值得先檢查再使用。**若…」 | 直接進入檢查本身 |
| 「**同樣需要先處理的，是…**」 | 整句刪除 |

**原則：段落第一句要嘛給一個具體事實、人名、年份、數字，要嘛給一個判斷。不要給「接下來我要…」。**

檢查方式：把每段第一句抽出來連讀。若讀起來像目錄或會議議程，就是中招。

### 病灶 2：跨節交叉引用

「第五節最後一小節會回到它們」「第二節已經量化過」「這個範圍差在第七節談存活者偏差時還會用到」。

這些是寫給審稿人看的，不是寫給讀者看的。**全部刪除。** 若某個概念真的需要在後面被喚起，靠內容自然承接。

目標：正文中 `第[一二三四五六七]節` 出現次數 = **0**。

### 病灶 3：路線圖段落

「以下的討論依序處理六件事。第二節檢查…第三節把…第四節檢驗…」

**整段刪除。** 讀者有章節標題，不需要目錄。

### 病灶 4：編號鷹架

「第一條證據／第二條證據」「第一個限定／第二個限定／第三個限定」「第一，…第二，…第三，…」

拆掉編號，讓段落自然並列。內容本來就分得開。

> 例外：當項目**確實需要被逐一指涉**（例如「三個條件」後面每一條都會被單獨回頭討論），編號可以留。判準是：刪掉編號之後，讀者會不會找不到東西。

## ⛔ 絕對不可動

**核心區分：刪掉「誠實的鷹架」，保留「誠實的內容」。**

- 「這一步在文中被明確標示為推論」→ 鷹架，**刪**
- 「這一步沒有直接的時序證據」→ 內容，**留**

具體不可動的清單：

1. **所有數字**（金額、比率、件數、年份、條號）
2. **引用編號 `<sup>N</sup>` 與參考資料的 1:1 對應**。合併或刪段時，引用標記必須跟著內容移動。完成後務必自驗
3. **實質的誠實限定語**，特別是 fact-check 報告要求補的那些。典型如：
   - 樣本／地理涵蓋範圍的限制
   - 某一步是推論而非經驗發現
   - 存在命題的限定（「在本文可及的案例中」不可改回全稱）
   - 來源等級與資料缺口的說明
4. **frontmatter 全部欄位**與開頭的 AI 協作揭露段
5. intake 的 must_avoid 全部條目

## 篇幅

拆完鷹架自然會短，典型減幅 **15–20%**。

不要為了湊字數保留贅段，也**不要為了達到字數目標而刪證據或限定語**。若拆完仍高於目標，回報並說明「剩下的每段不是帶引用的證據就是限定語」，由主 agent 決定，不要自行砍內容。

## 輸出

1. `<job-dir>/final/article-final-v1-verbose.md`（**先備份原版**）
2. `<job-dir>/final/article-final.md`（覆寫為拆鷹架版）

## 自驗（覆寫前必做）

- [ ] 引用編號 1–N 連續、無斷號、無孤兒，與參考資料 1:1
- [ ] 跨節交叉引用 `第[一二三四五六七]節` = 0
- [ ] 關鍵數字逐一比對原版，無缺失、無變動
- [ ] fact-check 要求的限定語全數仍在
- [ ] `——` 與正文全形冒號符合禁則
- [ ] 每段第一句連讀，不像目錄

## 回報

正文字數（前 → 後、減幅%）、引用完整性、四類病灶各清除幾處、以及**一段 before/after 對照**（各約 100 字，挑最能代表改動的一段）。
