## 研究方法要求

### 推理鏈

請為每個子論點標明推理類型和強度：

| 代號 | 類型 | 說明 | 風險 |
|------|------|------|------|
| D | 演繹 | 前提為真則結論必然為真 | 低 |
| I | 歸納 | 從多個案例歸納出模式 | 中 |
| A | 類比 | 從類似場景推論 | 中高 |
| Ab | 溯因 | 推測最佳解釋 | 高 |
| C | 因果 | 主張 X 導致 Y | 須區分相關 vs 因果 |

**強制規則**：
- 所有因果主張（C）必須區分「觀察到的相關性」和「驗證的因果關係」
- 每個因果主張必須附帶一個反事實問題（如果 X 沒發生，Y 還會嗎？）
- 每個子論點必須標明推理強度（強/中/弱）和至少一個反例或限制

### 來源蒐集（四象限法）

你的來源必須覆蓋以下四個象限：

```
              學術/理論         真實案例
  成功/正面   ≥2 個來源        ≥2 個案例
  失敗/負面   ≥1 個來源        ≥2 個案例
```

- 成功案例數量 ≤ 失敗案例數量 + 1（避免倖存者偏差）
- 不能只有歐美案例，需要涵蓋至少一個亞洲或非西方案例
- 核心主張必須有 A 級來源（學術論文、官方文件、審計報告）
- C 級來源（媒體報導）不可單獨支撐核心結論

來源分級：
- **A 級**：學術論文（peer-reviewed）、法規、政府/國際組織報告、審計報告
- **B 級**：官方政策頁面、有責任主體的機構文件
- **C 級**：媒體報導、blog、二手摘要

### 案例資料

每個案例必須提供以下結構化資料：
- 名稱、類型、成立年份
- 狀態（active / struggling / failed / acquired）
- 法律結構
- 收入模式
- 年收入（標明來源 + 年份 + 幣別）
- 使用者規模（標明來源 + 查閱日期）
- 治理模式
- 關鍵風險
- 失敗原因（如適用）

### 引用規則

- 所有數字標明年份和來源
- 貨幣標明幣別（USD / EUR / TWD）
- 提供完整 URL 或 DOI
- 網頁來源標明查閱日期
- 不要捏造引用——證據不足時寫「待查核」

### 禁止事項

- 不要把這份 prompt 本身當成外部引用
- 不要憑空補 citation
- 不要直接交付最終發稿文章
- 不要用 prompt 語言寫正文（「我要維持的語氣」「這裡需要更正式」）
- 不要只寫成功案例
